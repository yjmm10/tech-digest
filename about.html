关于 tech-digest（技术周报归档）

tech-digest 是一份每周自动更新的中文技术情报周报（AI 技术周报）：聚合 arXiv 论文速递、Semantic Scholar、OpenAlex 学术动态、GitHub 开源趋势与 RSS 资讯，由大模型生成中文摘要与相关性评分，每周五发布并提供 RSS 订阅。

项目定位

tech-digest 是一个开源的自动化技术情报管线与中文 AI 技术周报档案站：Python 完成多源采集与 GLM 摘要评分，条目按 Schema v1 落盘为 JSON 归档，React 档案站提供检索 / 日历 / Markdown 阅读，GitHub Actions 定时构建并发布至 GitHub Pages。

数据来源

  • arXiv —— 前沿论文速递（按关键词与时间窗检索）
  • Semantic Scholar —— 学术论文与引用数据
  • OpenAlex —— 开放学术数据
  • GitHub Trending —— 开源项目周榜趋势
  • GitHub Search —— 关键词仓库检索
  • RSS —— 自定义技术资讯订阅源

产出与规模

截至 2026-11-26，已归档 38 期周报、1025 条情报条目，覆盖 6 类公开信息源；每周五 UTC 12:00 自动更新。

维护者

个人维护的非商业开源项目（GitHub：yjmm10/tech-digest）。条目均来自公开信息源，AI 摘要与评分由大模型生成、仅供参考。

入口

  • 首页与数据站
  • RSS 订阅（每期全文）
  • 结构化数据 viewer-data.json（Schema v1）
  • llms.txt（AI 上下文文件）
