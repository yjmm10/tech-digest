能力特性

一套可自部署的技术情报自动化管线

六源统一调度

arXiv、Semantic Scholar、OpenAlex、GitHub Trending / 检索与 RSS 订阅源，共用关键词与时间窗配置，一次运行全量覆盖。

AI 摘要与评分

GLM 大模型为每条条目生成中文摘要与 0–10 相关性评分；主模型异常时自动切换备用网关，产出不中断。

三级去重清洗

同期次、单期内与跨期按链接三级去重，跨期保留最早记录，确保归档条目唯一、可追溯。

多维检索回溯

关键词、来源、评分、时间窗与日历自由组合筛选，数据一次加载、全量在客户端完成，交互零延迟。

Schema v1 结构化归档

每期落盘为独立 JSON（含 Markdown 原文与元数据），历史数据可恢复、可迁移、可二次加工。

自动发布与订阅

CI 自动构建 GitHub Pages 档案站并生成 RSS 源，抓取完成即上线，全程无需手动运维。

运作方式

从信息源到归档发布，全流程由 CI 自动完成

  1. 01

    定时抓取

    GitHub Actions 每周五 UTC 12:00 定时触发，多源并发拉取最新内容

  2. 02

    清洗去重

    同期次 / 单期内 / 跨期三级去重，过滤无效与重复条目

  3. 03

    AI 摘要评分

    GLM 生成中文摘要与相关性评分，备用模型自动接管异常

  4. 04

    归档发布

    按 Schema v1 落盘，CI 构建 Pages 站点与 RSS 并推送上线

常见问题

关于本项目的快速答案

tech-digest 是什么？

tech-digest 是一份每周自动生成的中文技术情报周报与配套开源管线：聚合六类公开信息源，由 GLM 大模型生成中文摘要与相关性评分，三级去重后结构化归档，支持全文检索、日历回溯与 RSS 订阅。

周报覆盖哪些数据来源？

arXiv 前沿论文、Semantic Scholar、OpenAlex 学术数据、GitHub Trending 周榜、GitHub 关键词检索与自定义 RSS 订阅源，共用关键词与时间窗配置，一次运行全量覆盖。

周报多久更新一次？

每周五 UTC 12:00 由 GitHub Actions 定时触发，抓取完成后自动构建发布到 GitHub Pages，并同步生成 RSS 订阅源与 JSON 归档。

如何订阅或引用本站内容？

通过 feed.xml 订阅 RSS 可获取每期全文；本站内容公开，欢迎引用，引用时请注明来源链接 https://yjmm10.github.io/tech-digest/。
